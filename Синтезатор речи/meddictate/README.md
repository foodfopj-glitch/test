# МедДиктовка — офлайн-диктовка медицинского текста

Плавающее мини-око́шко, которое **печатает речь прямо в то поле, где стоит курсор**:
ЕМИАС, Word, браузер, мессенджер — любое приложение. Работает **без интернета**,
понимает **русский язык** и **медицинскую терминологию** (препараты, диагнозы,
исследования, шаблоны осмотра). Собирается в **один портативный `MedDictate.exe`** —
без установки, можно носить на флешке.

```
нажали Ctrl+Alt+Space  →  говорите  →  текст печатается в активное поле  →  ещё раз нажали, стоп
```

---

## Что уже сделано и проверено

| Проверка | Результат |
|---|---|
| Скорость распознавания | ~8,6× быстрее реального времени (20 с речи ≈ 2,3 с на слабом CPU) |
| Точность на медицинских терминах | словарь 580 терминов; из них 282 модель не знает и их вытаскивает фонетический «спасатель» |
| Числа и дозировки | «температура тридцать восемь и пять» → `38,5`; «сто сорок на девяносто» → `140/90`; «пятьсот миллиграмм» → `500 мг` |
| Защита обычного текста | проверено автотестами: посторонняя речь словарём не переделывается |
| Живая печать | текст появляется через ~1 с после начала фразы, уточнения переписывают хвост |
| Тесты | 26 автотестов, включая полный путь «звук → распознавание → коррекция → печать в поле» |

## Как получить `MedDictate.exe`

### Вариант 1 — собрать в облаке GitHub (рекомендую, Python на ПК не нужен)

1. Загрузите эту папку в свой репозиторий на GitHub.
2. Вкладка **Actions** → **«Сборка MedDictate.exe»** → кнопка **Run workflow**.
3. Через ~5 минут откройте завершённый запуск и скачайте артефакт
   **MedDictate-windows-x64** — внутри один файл `MedDictate.exe`.

Готовый workflow лежит в `.github/workflows/build-windows.yml`. Если пометить
коммит тегом (`git tag v1.0 && git push --tags`) — exe автоматически приложится
к релизу.

### Вариант 2 — собрать на своём компьютере

Нужен только Python 3.10–3.12 с [python.org](https://www.python.org/downloads/)
(при установке отметить галочку *Add python.exe to PATH*).

Двойной щелчок по **`build.bat`** — скрипт сам:
поставит зависимости → скачает русскую модель (45 МБ) → прогонит самопроверку →
соберёт `dist\MedDictate.exe`.

Сборка без bat-файла:

```bat
pip install -r requirements.txt pyinstaller
python tools\fetch_model.py
python -m PyInstaller --noconfirm --clean meddictate.spec
```

**Хотите точнее?** Большая модель (1,8 ГБ, заметно лучше на сложных терминах):

```bat
python tools\fetch_model.py --big
python -m PyInstaller --noconfirm --clean meddictate.spec
```

### Проверка без сборки

```bat
pip install -r requirements.txt
python meddictate.py            :: запуск из исходников
python meddictate.py --selftest :: проверка корректора без микрофона
python meddictate.py --model-check
python -m pytest tests -q
```

## Как пользоваться

1. Запустите `MedDictate.exe` (при первом запуске модель распаковывается в
   `%APPDATA%\MedDictate` — около 10 секунд).
2. Поставьте курсор в нужное поле (ЕМИАС, Word, поле заметок — что угодно).
3. Нажмите **Ctrl + Alt + Space** — окошко загорится зелёным, говорите обычным
   темпом. Текст печатается сразу, по мере распознавания.
4. Ещё раз **Ctrl + Alt + Space** — стоп. Точка в конце поставится сама.

| Клавиши / кнопки | Действие |
|---|---|
| `Ctrl+Alt+Space` | начать / остановить диктовку (режим «по клавише») |
| `Ctrl+Alt+C` | непрерывный режим: слушает, пока не выключите |
| `Ctrl+Alt+Z` | стереть весь текст, вставленный в этой диктовке |
| кнопка «—» | свернуть окошко в трей (программа продолжает работать) |
| кнопка «🎙 клавиша / 🔁 непрерывно» | переключить режим прямо из окошка |
| кнопка «Стереть» | убрать вставленный текст |
| кнопка «Копия» | положить распознанный текст в буфер обмена (если поле не приняло) |
| значок в трее | меню: показать окошко, сменить режим, настройки, выход |

**Два режима** (выбираются в настройках или кнопкой в окошке):

* **по горячей клавише** — микрофон открывается только на время диктовки; удобно
  на приёме, чтобы программа ничего не слышала между записями;
* **непрерывно** — слушает постоянно, пауза по `Ctrl+Alt+C`; удобно, когда нужно
  диктовать много подряд.

Дополнительно: **автостоп после тишины** (по умолчанию 3 секунды) — можно
говорить фразу, отвлечься, и диктовка сама остановится.

## Распознавание «на слух»: примеры работы словаря

Ниже — реальные распознавания модели (проверялись на синтезированной речи) и то,
что печатает программа:

| Модель услышала | Программа напечатала |
|---|---|
| «съем жалуется на боль в груди» | Пациент жалуется на боль в груди |
| «диагноз не больничная пневмония» | Диагноз внебольничная пневмония |
| «назначена максим лента по пятьсот миллиграмм» | Назначена амоксициллин по 500 мг |
| «эхо кардиолог графе» | эхокардиография |
| «артериальное давление сто сорок на девяносто» | артериальное давление 140/90 |
| «температура тридцать восемь и пять» | температура 38,5 |
| «лейкоциты девять два» | лейкоциты 9,2 |
| «девяносто восемь процентов» | 98% |
| «два миллиграмм на килограмм» | 2 мг/кг |

Слова, которые программа исправила, показываются в окошке строкой
**«Исправлено: «макси цели» → «мексидол»»**. Если подстановка показалась
подозрительной (например, название препарата) — сомнительные правки помечаются
словом *проверьте*, и вы точно знаете, что стоит перечитать.

## Настройка словаря под свою специальность

Словарь — сердце точности. Он состоит из встроенного списка (580 терминов:
диагнозы, препараты, исследования, шаблоны осмотра) и **ваших файлов**, которые
создаются автоматически:

```
%APPDATA%\MedDictate\terms_user.txt          # свои термины, по одному в строке
%APPDATA%\MedDictate\replacements_user.txt   # свои замены:  слышно = писать
```

Открыть их можно прямо из окна настроек (вкладка **Словарь**) — после сохранения
изменений программа перечитывает словарь сразу, перезапуск не нужен.

Пример `terms_user.txt`:

```
# препараты и термины вашего профиля
апиксабан
фиброгастродуоденоскопия
транскраниальная магнитная стимуляция
```

Пример `replacements_user.txt`:

```
# слышим = пишем (регистр и ё/е не важны; можно несколько слов слева)
кардиограмма = ЭКГ
узи сердца = Эхо-КГ
давление на левой руке = АД на левой руке
точка с запятой = ;
новая строка = \n
```

Проверить, что модель «слышит» ваши термины, можно кнопкой
**«Проверить словарь под модель»** в настройках или командой
`python meddictate.py --model-check`.

> Если термин есть в лексиконе модели — он почти не трогается (защита от лишних
> правок). Если модель его не знает — включается фонетический «спасатель»,
> который узнаёт термин даже в сильно перевранном виде.

## Настройки (вкладки окна настроек)

* **Основное** — режим, горячие клавиши, автозапуск с Windows, старт в трее.
* **Звук** — выбор микрофона, усиление, отсечение тишины (VAD) и её порог,
  автостоп по тишине, кнопка «Проверить микрофон» с индикатором уровня.
* **Вставка** — способ ввода (символы / скан-коды / буфер обмена), живая печать,
  пауза между символами (если поле «проглатывает» быстрый текст),
  «печатать только в то окно, где начали» — защита от вставки текста не туда.
* **Коррекция** — строгость исправлений (ползунок), учёт лексикона модели,
  числа цифрами, сокращение единиц, голосовые знаки, заглавные буквы, точка в конце.
* **Словарь** — открыть свои файлы словаря, проверить их под модель, папка программы.

## Как это устроено

```
микрофон (sounddevice, 16 кГц)
        │  блоки по 0,25 с
        ▼
отсечение тишины (VAD)  ──►  распознавание Vosk (офлайн, русская модель)
                                     │
                                     ▼
                       коррекция: замены → термины по словарю →
                       числа, единицы, пунктуация, регистр
                                     │
                                     ▼
      печать в активное поле (SendInput, юникод) с перезаписью хвоста
```

Ключевые файлы:

| Файл | Назначение |
|---|---|
| `app/audio.py` | микрофон, VAD, индикатор уровня |
| `app/asr.py` | модель, поток распознавания, автостоп, подготовка словаря |
| `app/corrector.py` | фонетический «спасатель» терминов, защиты от лишних правок |
| `app/numerals.py` | числа, дозировки, единицы, пунктуация, регистр |
| `app/insert.py` | ввод текста в активное окно (`SendInput`), перезапись хвоста |
| `app/hotkeys.py` | глобальные горячие клавиши (`RegisterHotKey`) |
| `app/overlay.py` | мини-око́шко |
| `app/tray.py` | значок и меню трея |
| `app/settings_dialog.py` | окно настроек |
| `app/qt.py` | единый слой Qt: PySide6 (LGPL) или PyQt6 (GPL) |
| `data/terms_med.txt` | встроенный медицинский словарь |
| `data/replacements_med.txt` | встроенные замены и голосовые команды |
| `data/lexicon_report.txt` | отчёт: какие термины модель знает сама |

### Почему выбраны эти решения

* **Vosk, а не Whisper** — на слабом CPU без GPU Vosk даёт ~8,6× реального времени
  при крошечной модели 45 МБ; легковесные модели Whisper на таком железе
  заметно отстают, а большие требуют GPU.
* **Печать символами, а не вставка из буфера** — не затирает буфер обмена и
  не «щёлкает» окнами; текст встаёт именно в позицию курсора.
* **Окно не забирает фокус** — клики по кнопкам окошка не мешают печати.
* **Словарь правит хвост на лету** — исправление термина видно почти сразу,
  а не после конца фразы.

## Ограничения, о которых стоит знать

* **Сборка exe возможна только на Windows.** PyInstaller не умеет
  кросс-компиляцию: из Linux/macOS `.exe` не получить. Именно поэтому сборка
  идёт либо через GitHub Actions, либо на вашем ПК через `build.bat`.
* **Первая секунда фразы может мигать** — модель уточняет первые слова по ходу
  речи; программа перезаписывает хвост, поэтому в поле остаётся верный вариант.
* **Названия препаратов — самое рискованное место.** Модель может услышать
  «мексидол» вместо «амоксициллин»: оба слова есть в её словаре, и по звучанию
  они похожи. Защита: такие замены помечаются в окошке словом *проверьте*.
  Чем чаще препарат встречается в вашей практике — тем полезнее добавить его
  в `terms_user.txt`, тогда исправление станет устойчивым.
* **Омонимы с числами**: «девяносто» → «90» верно, но «девяносто восемь»
  рядом с показателем превращается в «98%» только при слове-единице;
  проверяйте строки с числами в лабораторных заключениях.
* **Диктовка — не распознавание чужой речи**: программа оптимизирована под
  запись «врач говорит заключение», а не под расшифровку диалога с пациентом.
* **Лицензии**: код — ваш, движок Vosk и русская модель — Apache 2.0,
  интерфейс — PySide6 (LGPL). Если собираете с PyQt6, действует GPL: такой exe
  нельзя распространять как закрытый продукт.

## Частые вопросы

**Текст не печатается в ЕМИАС, хотя в Блокноте всё работает.**
Откройте настройки → «Вставка»: попробуйте способ «Скан-коды клавиш», поставьте
паузу 20–40 мс и включите «Печатать только в то окно, где начали».
Если приложение запущено от имени администратора, обычные программы не могут
в него печатать — запустите МедДиктовку тоже от администратора (либо наоборот,
снимите запуск от администратора с ЕМИАС).

**Микрофон не виден в списке.** Нажмите «Обновить» в настройках (вкладка «Звук»);
программа видит устройства через Windows, установка драйверов не нужна.

**Хочу, чтобы программа не переделывала слова.** Сдвиньте ползунок «Строгость
исправлений» правее или снимите галочку «Исправлять термины по словарю» —
останутся только числа и единицы.

**Как добавить свой препарат так, чтобы он распознавался всегда?**
Внесите его в `terms_user.txt` (вкладка «Словарь») — и говорите чётко,
термин попадёт в словарь-подсказку для «спасателя».

**Программа мешает, когда я не диктую.** Она не слушает микрофон, пока не
нажата горячая клавиша (в режиме «по клавише») — микрофон занят только во время
диктовки. В непрерывном режиме есть автостоп по тишине.
