МЕДДИКТОВКА — диктовка медицинского текста  (версия 1.0.0)
=========================================================

Что это: мини-окошко, которое печатает вашу речь прямо в то поле,
где стоит курсор (ЕМИАС, Word, браузер). Работает без интернета,
понимает русский язык и медицинские термины.

--------------------------------------------------------------
КАК ПОЛУЧИТЬ ПРОГРАММУ (файл MedDictate.exe)
--------------------------------------------------------------
Способ 1 (Python на компьютере не нужен):
  1. Выложите эту папку в свой репозиторий на GitHub.
  2. Вкладка Actions -> "Сборка MedDictate.exe" -> Run workflow.
  3. Через ~5 минут скачайте артефакт MedDictate-windows-x64 -
     внутри один файл MedDictate.exe.

Способ 2 (на своём компьютере, нужен Python 3.10-3.12 с python.org):
  1. Двойной щелчок по build.bat
  2. Ждёте 3-5 минут. Готовый файл: dist\MedDictate.exe

--------------------------------------------------------------
КАК ПОЛЬЗОВАТЬСЯ
--------------------------------------------------------------
  1. Запустите MedDictate.exe (первый запуск ~10 секунд: готовится модель).
  2. Поставьте курсор в нужное поле.
  3. Ctrl + Alt + Space  — окошко загорится зелёным, говорите.
     Текст печатается сразу.
  4. Ещё раз Ctrl + Alt + Space — стоп.

  Ctrl + Alt + C  — непрерывный режим (слушает, пока не выключите)
  Ctrl + Alt + Z  — стереть всё, что напечатала программа
  Кнопка "—"      — свернуть окошко в трей (программа продолжит работать)

--------------------------------------------------------------
СВОИ ТЕРМИНЫ И ПРЕПАРАТЫ
--------------------------------------------------------------
Окошко -> "⚙" (Настройки) -> вкладка "Словарь" -> "Открыть terms_user.txt"
Впишите свои термины по одному в строке, сохраните - программа
подхватит их сразу, перезапуск не нужен.

Есть также файл замен: replacements_user.txt
Формат:  слышно = писать     (например:  кардиограмма = ЭКГ)

--------------------------------------------------------------
ЕСЛИ ЧТО-ТО НЕ ТАК
--------------------------------------------------------------
* Текст не печатается в ЕМИАС, а в Блокноте работает:
  Настройки -> "Вставка" -> способ "Скан-коды клавиш", пауза 20-40 мс,
  включить "Печатать только в то окно, где начали".
  Если ЕМИАС запущен от администратора - запустите МедДиктовку так же.
* Что-то переделывается зря: сдвиньте "Строгость исправлений" правее
  или выключите "Исправлять термины по словарю".
* Журнал работы: %APPDATA%\MedDictate\meddictate.log
